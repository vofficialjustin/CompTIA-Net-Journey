Exam Objectives (N10-009)
1.0 Networking Concepts — 23%
1.1 Explain concepts related to the OSI reference model
1.2 Compare and contrast networking appliances, applications, and functions
1.3 Summarize cloud concepts and connectivity options
1.4 Explain common networking ports, protocols, services, and traffic types
1.5 Compare and contrast transmission media and transceivers
1.6 Compare and contrast network topologies, architectures, and types
1.7 Explain routing technologies and bandwidth management concepts
1.8 Explain the purposes of network services
1.9 Compare and contrast IPv4 and IPv6 addressing schemas
1.10 Explain switching technologies
2.0 Network Implementation — 20%
2.1 Explain characteristics of routing technologies
2.2 Given a scenario, configure switching technologies and features
2.3 Given a scenario, install and configure wireless devices and technologies
2.4 Explain important factors of physical installations
3.0 Network Operations — 19%
3.1 Explain the purpose of organizational documents and policies
3.2 Explain high availability and disaster recovery concepts and characteristics
3.3 Given a scenario, use network monitoring technologies
3.4 Given a scenario, use organizational processes to facilitate network operations
3.5 Given a scenario, use remote access methods
4.0 Network Security — 14%
4.1 Explain the importance of basic network security concepts
4.2 Summarize various types of attacks and their impact on the network
4.3 Given a scenario, apply network security features, defense techniques, and solutions
5.0 Network Troubleshooting — 24%
5.1 Explain the network troubleshooting methodology
5.2 Given a scenario, troubleshoot common cabling and physical interface issues
5.3 Given a scenario, troubleshoot common issues with network services
5.4 Given a scenario, troubleshoot common performance issues
5.5 Given a scenario, use the appropriate tool or protocol to solve networking issues
